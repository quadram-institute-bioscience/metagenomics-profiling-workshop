## Overview

In this guided session, we explore pre-computed HUMAnN3 results from the coffee bean fermentation time series. HUMAnN3 takes a long time to run, so the results have been computed for you.

You'll learn to:
- Understand the HUMAnN3 output files
- Follow how pathway abundances change over the fermentation
- Use stratified outputs to see which species contribute to a function
- Investigate a pathway of your choice

All the code is ready in an R Markdown document: **you don't need to know R**. You will run the code chunk by chunk, look at the results, and answer the questions.

## HUMAnN3 output files

HUMAnN3 produces three main output files per sample.

| File | Content | Units |
|---|---|---|
| `genefamilies.tsv` | Abundance of each gene family (UniRef90 IDs) | RPK (reads per kilobase): read counts corrected for gene length |
| `pathabundance.tsv` | Abundance of each MetaCyc pathway | Here normalized to CPM (copies per million) |
| `pathcoverage.tsv` | Fraction of the steps of each pathway that are detected | 0 to 1 |

Two special lines appear in these files:
- **UNMAPPED**: reads that didn't match any gene in the database. This is normal: many sequences are not in reference databases.
- **UNINTEGRATED**: genes detected but not part of any known pathway. This is normal too: not all genes belong to characterized pathways.

Each pathway line starts with the **MetaCyc ID**, followed by the pathway name. For example, in the merged pathway table:

```
# Pathway                                 ERR2231567  ERR2231569  ...
UNMAPPED                                  628312      552912      ...
UNINTEGRATED                              339804      407833      ...
FERMENTATION-PWY: mixed acid fermentation 70.472      121.783     ...
```

> In CPM, all the values of a sample (including UNMAPPED and UNINTEGRATED) add up to one million. Just like the taxonomic profiles this morning, these are **relative** values.

### Stratified vs unstratified

HUMAnN3 reports each function twice:
- **Unstratified lines** (no `|`): the total abundance of the function in the community
- **Stratified lines** (with `|`): the contribution of each species to this function

```
FERMENTATION-PWY: mixed acid fermentation
FERMENTATION-PWY: mixed acid fermentation|g__Genus.s__Genus_species
```

Stratification tells us **who does what**:
- **Functional redundancy**: many species carry the same function, so the function can be maintained if one species declines
- **Specialization**: a function is carried by one or a few species, and is lost if they disappear

### 1. Understanding the output structure

We load the gene families of one sample (T0) and look at the stratified and unstratified lines, and at the UNMAPPED line.

> **Question:** how much of the T0 sample is UNMAPPED? Is it more or less than the unclassified fraction found by the taxonomic profilers this morning?

### 2. Load all samples

We load the merged pathway tables (unstratified and stratified) for the six samples, check that the values are in CPM, and add the timepoint of each sample.

### 3. Global overview

- **Pathway richness:** how many pathways are detected in each sample?
- **PCoA (Bray-Curtis):** how different are the functional profiles of the samples? The line connects the samples in time order.

> **Questions:**
> - Does pathway richness increase or decrease over time?
> - Is there a clear trajectory of functional change during fermentation? Which samples are most similar?

### 4. Deep dive: mixed acid fermentation

We follow one pathway, **mixed acid fermentation** (FERMENTATION-PWY), over time, then look at which species contribute to it.

> Note: the species contributions usually add up to less than the community total, and part of each function is often `unclassified` (not assigned to a known species).

> **Questions:**
> - Is there a clear temporal trend?
> - Is this function carried by many species or by a few?
> - Do the main contributors change over time?
> - Are the main contributors the same taxa that dominated the taxonomic profiles this morning?

## To go further

### Pathway coverage

The `pathcoverage.tsv` file shows which fraction of the steps of each pathway is detected (0 to 1). It helps distinguish complete pathways from incomplete ones: a pathway with a high abundance but a low coverage may come from a few abundant genes of an incomplete pathway.

### Normalization

**Gene families** are in RPK (reads per kilobase), corrected for gene length only. To compare samples, convert them to CPM or relative abundance:

```bash
humann_renorm_table --input genefamilies.tsv --output genefamilies_cpm.tsv --units cpm
humann_renorm_table --input genefamilies.tsv --output genefamilies_relab.tsv --units relab
```

**General rules:**
- Comparing the same feature across samples: CPM
- Comparing different features within a sample: relative abundance
- Statistical testing: depends on the tool (for example, DESeq2 uses raw counts, ALDEx2 uses CLR-transformed values)
- Always state which normalization you used in your methods and figure legends

### Regrouping to other functional databases

HUMAnN3 gene families use UniRef90 IDs, but you can regroup them to other functional classifications:

```bash
# Regroup to EC numbers (enzymes)
humann_regroup_table --input genefamilies.tsv --output genefamilies_ec.tsv --groups uniref90_ec

# Regroup to Gene Ontology
humann_regroup_table --input genefamilies.tsv --output genefamilies_go.tsv --groups uniref90_go

# Regroup to KEGG Orthology
humann_regroup_table --input genefamilies.tsv --output genefamilies_ko.tsv --groups uniref90_ko
```

- **GO**: broad functional categories
- **EC**: enzyme-focused questions, connecting to metabolomics data
- **KEGG**: pathway integration, connecting to other omics data
